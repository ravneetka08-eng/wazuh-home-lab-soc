# Detection Engineering

## Overview

Detection engineering is the process of designing, testing, validating, and improving security detections to identify malicious activity while minimizing false positives.

This project explored how Wazuh processes logs, applies decoders, matches rules, and generates alerts for security events.

Used to detect

- SQL Injection

- File Upload attempts

Monitored

- sudo
- PAM authentication

Monitored

- /etc

- /usr/sbin

Generated alerts when monitored files changed.
